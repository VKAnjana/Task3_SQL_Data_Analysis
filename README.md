# Task3_SQL_Data_Analysis

## Objective

The objective of this project is to use SQL queries to extract and analyze data from an Ecommerce database using MySQL.

## Tools Used

- MySQL Server
- MySQL Workbench

## Database

Ecommerce_SQL_Database

- Created an Ecommerce database.
- Created four tables: Customers, Products, Orders, and OrderDetails.
- Inserted sample data into all tables.
- Retrieved data using SELECT statements.
- Filtered records using the WHERE clause.
- Sorted data using ORDER BY.
- Grouped data using GROUP BY.
- Performed INNER JOIN, LEFT JOIN, and RIGHT JOIN operations.
- Used aggregate functions such as SUM() and AVG().
- Wrote a subquery to analyze data.
- Created a VIEW for simplified data analysis.
- Created an INDEX to improve query performance.

## Outcome

This project helped me understand how to create and manage a relational database, write SQL queries to analyze data, perform joins, use aggregate functions, create views, and optimize queries using indexes.
